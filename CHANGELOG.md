# Changelog

## 0.1.0

Initial implementation of preserved skill sources and ordinary writable derivatives for Hermes.

- Profile-bound raw snapshots, immutable checkpoints and candidate review.
- Deterministic Git three-way reconciliation with explicit whole-file conflict decisions and captured base/local/source/proposal previews.
- Fresh native skill publication and rollback, exact revision/review-hash checks, no-clobber directory rename, and interrupted-operation recovery.
- Operator CLI, opt-in native Desktop page, authenticated plugin routes, and three bounded read-only agent tools.
- Portable path checks and executable masks, verified Windows capture/staging, Linux/macOS no-replace publication, and offline runtime checks.

A clean textual merge is not a behavior test. Publication is separate from native skill-edit approvals. See the QA report for verified coverage and limitations rather than inferring support from this feature list.
