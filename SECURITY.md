# Security and local data

See [the security guide](docs/SECURITY.md) for source/export boundaries, the native approval boundary, local data, and runtime dependencies. See [recovery](docs/RECOVERY.md) before retrying an interrupted publication.

Report suspected vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature when available. If that feature is unavailable, open an issue requesting a private contact without publishing a proof of concept or private skill content. Include the affected version, platform, and sanitized error. Do not post credentials, full environment dumps, skill text, or private paths in a public issue.
